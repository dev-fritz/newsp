# AGENTS.md

Repository-wide execution contract for coding agents. Layer-specific rules live next to the
code and take precedence inside their folder:

- [`api/AGENTS.md`](api/AGENTS.md) — Go backend (HTTP API, worker, migrations).
- [`web/AGENTS.md`](web/AGENTS.md) — React Router frontend and its BFF.

## Project intent

`newsp` is a self-hosted, multi-user, open source (AGPL-3.0) market radar. It collects news and
discussions from public sources, then uses AI models (local or hosted) to write a daily market
report per user and software project ideas that never repeat — a near-duplicate idea becomes a
new version of the existing one.

The repository has three halves with clear ownership:

1. **Collection** — connectors and the worker that fetch, normalize and embed items (`api/`).
2. **Generation** — report and idea pipelines on top of a provider-agnostic AI layer (`api/pkg/ai`).
3. **Experience** — the web app and its BFF, which owns the user session (`web/`).

Do not blur those responsibilities without a measured reason.

## Sources of truth

Before changing code, read the smallest relevant set of files:

1. The `AGENTS.md` of the folder you are touching.
2. [`docs/`](docs/) — how it works, architecture, configuration and the development guide.
3. [`CONTRIBUTING.md`](CONTRIBUTING.md) — required checks and commit rules.
4. [`SECURITY.md`](SECURITY.md) — when touching auth, sessions, outbound HTTP (SSRF), secrets or AI keys.
5. Existing tests closest to the code being changed.

## Non-negotiable rules

- **Measure, do not assert.** No claimed quality, cost or performance gain without a test or a
  reproducible number.
- **Never commit secrets** (`.env`, API keys, tokens) or raw third-party content beyond short
  synthetic fixtures.
- **Ideas never duplicate.** Any change to idea generation must keep the dedup path (embedding
  similarity → LLM judge → merge into a new version) and its tests green.
- **AI providers stay swappable.** Services reach models through `AIGateway` and small ports
  (`Embedder`, `GenerationAI`); providers implement `ai.Provider`. Never depend on a vendor API
  shape. Local models must keep working.
- **Do not edit `CHANGELOG.md` by hand.** It is generated by git-cliff from Conventional Commits.
- Preserve API compatibility under `/api/v1` unless the task explicitly authorizes a break.

## Execution loop

1. **Orient** — read this file, the folder `AGENTS.md` and the code/tests you will touch.
2. **Plan the smallest coherent change** — state what will not change; define the acceptance
   command before editing.
3. **Implement one task** — focused diff, tests with the code, no opportunistic refactors.
4. **Prove it** — run the gates below and keep the real output.
5. **Record state** — blockers are reported as blockers; a task is done only when its gate is green.

## Gates

```bash
# api/
make check            # go vet, golangci-lint, go test -race, build

# web/
pnpm lint && pnpm typecheck && pnpm format:check && pnpm build
```
